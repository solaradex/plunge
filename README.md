# Plunge

Plunge is a local-first social and dating platform for adults to discover, chat with, make friends with, and meet people nearby based on location, interests, age preferences, and connection goals.

## Project

Plunge is being built for adults 18+ with privacy, safety, real-time communication, and local discovery as core principles.

## Planned stack

- Next.js
- TypeScript
- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Storage
- Supabase Realtime

## Development

The application is under active development.
